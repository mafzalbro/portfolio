## Style Guidelines:

- Background: Dark, desaturated yellow (#332F22) to create a sophisticated and professional feel.
- Primary: Saturated, warm red (#F2542D) for an eye-catching and energetic highlight.
- Accent: A bright, slightly desaturated orange (#F0A74B) to complement the primary color and draw attention to key elements. 
- Font Pairing: 'Space Grotesk' (sans-serif) for headlines, 'Inter' (sans-serif) for body.
- Modern and minimalist icons, resembling those used in desktop applications, to enhance user experience. To increase readability, make icons outlined style.
- Desktop-application-like layout with clear sections, intuitive navigation, and prominent display of key information, giving an interactive experience. Employ a card-based layout.
- Smooth and subtle animations and transitions for enhanced user experience and visual appeal, with particular focus on animations between sections and project showcases. Integrate 3D animated elements using React Three Fiber.
